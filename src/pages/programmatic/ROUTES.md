# Programmatic page routes — integration guide

Generated by `scripts/seo-bot/generate-pages.mjs`. **Do not add one route per page** — four
param routes serve all 136 pages. Unknown slugs and pages in unreleased batches redirect to
`/404` from inside the component, so the catch-all `NotFound` route keeps working.

## 1. Lazy imports (top of `src/App.tsx`, next to the other `lazy()` calls)

```tsx
const SalaryProgrammaticPage = lazy(() =>
  import("./pages/programmatic/ProgrammaticPage").then((m) => ({ default: m.SalaryProgrammaticPage }))
);
const MortgageProgrammaticPage = lazy(() =>
  import("./pages/programmatic/ProgrammaticPage").then((m) => ({ default: m.MortgageProgrammaticPage }))
);
const AutoLoanProgrammaticPage = lazy(() =>
  import("./pages/programmatic/ProgrammaticPage").then((m) => ({ default: m.AutoLoanProgrammaticPage }))
);
const GrowthProgrammaticPage = lazy(() =>
  import("./pages/programmatic/ProgrammaticPage").then((m) => ({ default: m.GrowthProgrammaticPage }))
);
```

## 2. Routes (inside `<Routes>`, before the `*` catch-all)

Follow the same `<Suspense>` fallback pattern the other lazy routes use:

```tsx
{/* Programmatic SEO pages (src/data/programmatic/manifest.json) */}
<Route
  path="/salary/:slug"
  element={
    <Suspense fallback={<PageLoadingSpinner />}>
      <SalaryProgrammaticPage />
    </Suspense>
  }
/>
<Route
  path="/mortgage/:slug"
  element={
    <Suspense fallback={<PageLoadingSpinner />}>
      <MortgageProgrammaticPage />
    </Suspense>
  }
/>
<Route
  path="/auto-loan/:slug"
  element={
    <Suspense fallback={<PageLoadingSpinner />}>
      <AutoLoanProgrammaticPage />
    </Suspense>
  }
/>
<Route
  path="/savings/:slug"
  element={
    <Suspense fallback={<PageLoadingSpinner />}>
      <GrowthProgrammaticPage />
    </Suspense>
  }
/>
```

## Notes for the integrator

- `/salary/:slug` serves **two** categories: `salary` ("$60,000 a year is how much an hour")
  and `hourly` ("$22 an hour is how much a year"). The component disambiguates via the manifest.
- None of these paths collide with existing routes (`/calculators/*`, `/blog/*`, `/embed/*`).
- Publishing is controlled by `published` in `src/data/programmatic/manifest.json`
  (flipped batch-by-batch by `scripts/seo-bot/release-batch.mjs`). Unpublished pages 404 at
  runtime because the component checks the same manifest the sitemap uses — no route changes
  needed when a batch is released, just a rebuild.
- Regenerating content: `node scripts/seo-bot/generate-pages.mjs` (add
  `--publish-batches=1,2,...` to preserve already-released batches — check the current
  manifest before regenerating, since the default marks only batch 1 published).
- Sample URLs to smoke-test after wiring:
  - `/salary/60000-a-year-is-how-much-an-hour`
  - `/salary/22-an-hour-is-how-much-a-year`
  - `/mortgage/300000-mortgage-payment`
  - `/auto-loan/35000-car-loan-payment`
  - `/savings/how-much-will-10000-grow-in-20-years`
